# 生图提示词 Prompts — ILS 系统架构（5 张，逐张单独生成）

用法：在安装了 `ian-xiaohei-illustrations` skill 的 Codex 里，
逐张粘贴运行（`Use $ian-xiaohei-illustrations …` + 下方提示词），16:9 PNG 存到
`assets/ils-architecture-illustrations/`，按 `01-scale…05-drawers` 命名。
生成后按 skill 的 QA 清单检查：小黑是否动作主体、有无左上角标题、有无错字、
是否像 PPT——凡是不合格直接重生成并减少标注词。

Generate one standalone 16:9 horizontal Chinese article illustration.

老式杆秤 / 左边纸叠 / 右边印章砝码 / 画面边缘评审的手
