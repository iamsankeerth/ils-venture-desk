# 配图策略 Shot List — ILS 系统架构（5 张）

方法来源：`ian-xiaohei-illustrations` skill（先消化正文 → 只选认知锚点 → 每张一个结构 →
小黑承担核心动作 → 重新发明隐喻，不复刻旧案例）。
正文 = `docs/architecture/SYSTEM_ARCHITECTURE.md`。正式 mermaid 架构图保持精确，
这 5 张只负责 5 个认知锚点：一图一动作，不做说明书。

## Shot 1 — 说法≠证明（放在 §4.1 之后）

- **主题**：创始人提交的是说法，评审盖章后才是证明
- **核心意思**：`evidence_status`（待审/已批准）和 `criterion_result`（达标与否）是两条独立轨道；
  批准了文件真实性，不等于指标就达标（12、8 WAU 获批，2 周 WAU 照样 NOT_MET）
- **结构类型**：概念隐喻
- **小黑在做什么**：双手扶着一杆老式秤，左边托盘堆着一叠“说法”纸，右边托盘空着；
  只有评审的手丢下一枚印章砝码，右边才会下沉
- **建议元素**：老式杆秤 / 左边纸叠 / 右边印章砝码 / 评审的手（画面边缘一只即可）
- **中文标注词**：说法≠证明 / 待审 / 盖章才算数

## Shot 2 — Demand Bar≠通关（放在 §4.2 之前）

- **主题**：单项达标、Demand Bar 达标、Level 0 完成，是三层不同的箱子
- **核心意思**：WAU 两周达标只装满最小的盒子；Level 0 还要 5 颗定性钉子钉上盖，
  缺一颗都显示 "Not Yet Verified"，而不是失败
- **结构类型**：概念隐喻
- **小黑在做什么**：蹲在大木箱旁，箱里已放进两个小盒，怀里抱着 5 颗钉子，
  正为盖不上盖而发愁（盖子斜靠一边）
- **建议元素**：大木箱 / 两个小盒 / 5 颗钉子 / 斜靠的盖子
- **中文标注词**：单项达标 / 还差五颗钉子

## Shot 3 — 开票和回款只记一桶（放在 §5 之后）

- **主题**：`B-E02`（10 万开票）和 `B-E03`（6 万回款）是一条链，不是两笔收入
- **核心意思**：父子证据链用 `parent_evidence_id` 拴在一起，已验证账 = 10 万已开、
  6 万已收、4 万差额；历史基线（12 lakh）是另一口井，永远不混在一起算
- **结构类型**：系统局部
- **小黑在做什么**：双手各握一根水管（开票管、回款管），一起往同一个账本桶里倒水；
  脚边另一口井盖着盖子，上面贴着封条
- **建议元素**：两根水管 / 一个账本桶 / 脚边上锁的水井 / 封条
- **中文标注词**：开票 / 回款 / 只记一桶

## Shot 4 — 只换第二周（放在 §4.1 之后，与 Shot 1 相邻）

- **主题**：`A-E02-W2`（11 WAU）原子替换只动第二周，第一周纹丝不动
- **核心意思**：待审时 11 WAU 只是小黑手里举着的新卡（Pending Correction），
  verified 还是 12、8；批准那一刻才别上绳，第二周旧卡进留档盒
- **结构类型**：前后对比（左待审 → 右已批准）
- **小黑在做什么**：左半：站在晾衣绳下高举一张新卡，绳上两张旧卡纹丝不动；
  右半：新卡已别上绳（第二周位置），旧卡掉进脚边留档盒，第一周那张连角都没皱
- **建议元素**：晾衣绳 / 两张周卡 / 小黑手里的新卡 / 脚边留档盒
- **中文标注词**：第一周不动 / 只换第二周 / 旧卡留档

## Shot 5 — 七个抽屉（放在 §5 之前）

- **主题**：一个 venture 有 7 个独立状态维度，动一个，不碰其他
- **核心意思**：`programme_level`、`msl_eligibility`、`fundraising_preference` 等各有
  各的列和 provenance；"不募资" 永远不会擦掉 "Eligible for MSL"
- **结构类型**：系统局部
- **小黑在做什么**：站在七屉柜前，正拉开其中一个抽屉往里看，
  其余六个抽屉紧闭（其中一个挂着小锁），身体挡住半边柜门
- **建议元素**：七屉柜 / 拉开的一个抽屉 / 其余紧闭抽屉 / 一把小锁
- **中文标注词**：七个抽屉 / 各开各的
