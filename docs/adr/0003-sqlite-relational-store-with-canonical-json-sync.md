# Use SQLite Relational Persistence Paired with Canonical JSON Export/Seed

The assignment requires a runnable local workflow prototype, a configuration/source export containing the three anonymised cases and mock evidence, and high maintainability within a 6-hour build budget. We decided to use a lightweight Python **FastAPI** backend backed by built-in **SQLite (`sqlite3`)** and a plain **React (`.jsx`)** frontend, where the SQLite database auto-initializes from a canonical `seed_data.json` file and exposes one-click JSON export (`/api/export`), JSON import (`/api/import`), and state reset (`/api/reset`) endpoints. This gives staff relational integrity for evidence chains, criteria mappings, and immutable transition audit logs while allowing graders to inspect, export, or reload the entire multi-case state as a single portable JSON document.
