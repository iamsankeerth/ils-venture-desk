# ILS Venture Desk: No-Vite Frontend

This frontend no longer requires Vite, its React plugin, the npm registry, or `npm install`. It contains a prebuilt static UI in `dist/`, generated from the existing JSX components.

## Fastest way to run

From the **project root**, after installing the Python backend requirements:

```bash
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

Open **http://127.0.0.1:8000/**. FastAPI now serves the static UI and `/api` together. Node and npm are **not needed just to run the prebuilt frontend**.

## Offline rebuilding

Node.js 20+ is needed to *recompile* `.jsx` files, but no installation is needed:

```bash
cd frontend
npm run build
```

The build script (`tools/build.mjs`) uses locally bundled TypeScript and Tailwind compilers and writes `dist/app.bundle.js`, `dist/styles.css`, and `dist/index.html`.

## Two-server alternative

From the project root, start FastAPI on port 8000. In a second terminal:

```bash
cd frontend
npm run dev
```

Open **http://127.0.0.1:5173/**. A small Node.js server (`tools/dev-server.mjs`) serves the compiled assets and proxies `/api` to FastAPI, replacing the original Vite development-server role. It rebuilds at start; rerun after edits.

## Runtime compatibility note

The offline bundle uses locally vendored React 16/ReactDOM 16 runtime files plus a project-scoped compatibility layer for only the hooks used in these ILS components. This keeps the existing JSX screens interactive without a package registry, but **it is not React 19 and is not a production React replacement**. The original component source is retained. For a deployed production app, use a maintained React toolchain.

SVG icons are generated locally by `lucide-lite.js` instead of requiring `lucide-react` at runtime. CSS is generated by a locally vendored Tailwind compiler.

No external CDN, fonts or analytics services are required.

## Tests

```bash
# From project root; requires python dependencies and playwright + chromium
PYTHONPATH=. python -m pytest -q frontend/tests/test_offline_ui.py
```

The browser harness injects compiled assets into Chromium's `about:blank` because this audit environment blocks direct URL navigation. Browser API calls are forwarded to the *actual* FastAPI TestClient with a new disposable SQLite database for every test. The static FastAPI endpoint and standalone Node development server were separately checked by HTTP.

This is a small exercise implementation with simulated roles, **not production authentication**.
